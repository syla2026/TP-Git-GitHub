# Analyse et visualisation des données pluviométriques de quatre stations dans la région de Batna
## Présentation du projet
Ce projet porte sur l'analyse et la visualisation des données pluviométriques de quatre stations dans la région de Batna.
## Objectifs
- Organiser les données pluviométriques.
- Comparer les précipitations entre les quatre stations.
- Découvrir l'utilisation de Git et GitHub.
## Outils utilisés
- Git
- GitHub
